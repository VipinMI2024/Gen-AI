# Deep Learning & Computer Vision Assignments

This repository contains a collection of deep learning and computer vision assignments completed as part of coursework and self-practice. The notebooks cover fundamental to advanced concepts, including CNNs, image preprocessing, feature extraction, optimization techniques, transfer learning, and generative AI.

## Repository Structure

### 1. Basic Image Processing
- **Assignment 1, 2, 3 – Basic Image Processing.ipynb**  
  Covers image loading, resizing, grayscale conversion, filtering, thresholding, histogram analysis, and other foundational image-processing operations.

### 2. MNIST Classification
- **Assignment 4 – MNIST.ipynb**  
  Implements a neural network/CNN for handwritten digit classification using the MNIST dataset.

### 3. CIFAR-10 Classification
- **Assignment 5 – CIFAR-10.ipynb**  
  Builds a CNN for multi-class image classification using CIFAR-10.

### 4. CNN Architectures and Analysis
- **CNN Feature Maps.ipynb**  
  Visualizes convolutional feature maps to understand what the network learns.
- **CNN with Dropout and Batch Normalization.ipynb**  
  Demonstrates regularization and normalization techniques to improve model stability.
- **Compare Activation Function.ipynb**  
  Compares ReLU, LeakyReLU, Sigmoid, Tanh, and other activations.
- **Comparison (SGD vs Adam).ipynb**  
  Performance comparison of two popular optimizers.

### 5. Data Augmentation
- **Load and Preprocess CIFAR-10 with Augmentation.ipynb**  
  Implements data augmentation techniques such as rotation, flipping, zooming, and normalization.

### 6. Transfer Learning & Fine-Tuning
- **Fine-Tune ResNet50, Replace Classifier Head in InceptionV3, Save & Reload Model.ipynb**  
  Applies transfer learning, fine-tuning, and model saving/loading for custom datasets.

### 7. Feature Extraction
- **VGG16 for Feature Extraction.ipynb**  
  Uses VGG16 pretrained weights to extract high-level image features.

### 8. Advanced Architectures
- **U-NET.ipynb**  
  Implements U-Net for semantic segmentation tasks.
- **RNN.ipynb**  
  Introduces Recurrent Neural Networks with sequence-based examples.

### 9. Generative AI
- **GEN_AI_CV.ipynb**  
  Experiments with generative models for computer vision.
- **GenAI_14_18.ipynb**  
  Additional generative AI tasks and model explorations.

## Requirements
- Python 3.x
- TensorFlow or PyTorch
- NumPy
- OpenCV
- Matplotlib
- Scikit-learn
- Jupyter Notebook

Install dependencies:
```bash
pip install -r requirements.txt
```

## How to Use
1. Clone the repository:
```bash
git clone https://github.com/yourusername/yourrepo.git
```
2. Open the notebooks in Jupyter or VS Code.
3. Run all cells to reproduce the results.
